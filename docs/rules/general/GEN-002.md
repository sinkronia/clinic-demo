**Rule.** No passwords, tokens, API keys or connection strings with real credentials are committed. Use environment variables or the platform secret store.

**Why.** Anything pushed is effectively public and permanent.

**Correct.** Throwaway local values only in `docker-compose.yml` for the dev database.

**Incorrect.** A real API key in `appsettings.json`.
