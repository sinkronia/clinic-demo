**Rule.** Every domain term used in code, docs or API contracts comes from `docs/glossary.md`. If a term is missing, propose it with the `propose-rule` skill (as a glossary entry) before using it.

**Why.** One word per concept (Spanish for users, English in code) prevents drift between tools and people.

**Correct.** `Appointment` for "Cita". For an unlisted concept, open a proposal and wait for it.

**Incorrect.** Silently inventing `DentalChair`, `Seat` or `Chair` for a concept the glossary does not define.

**Exception.** None. The AI reviewer receives the glossary and flags unknown domain terms.
