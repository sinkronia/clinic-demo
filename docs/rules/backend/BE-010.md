---
id: BE-010
title: Create endpoints accept an Idempotency-Key header
applies_to: ["backend/src/Clinic.Api/**"]
verified_by: ["review:only"]
status: active
since: v0.1
---
**Rule.** Every `POST` that creates a resource accepts an `Idempotency-Key` header. Same key + same body returns the stored response; same key + different body returns `409` `idempotency.key_reuse`. Reuse the existing `IdempotencyRecords` mechanism.

**Why.** Clients retry on flaky networks; creates must not duplicate.

**Correct.** Mirror `POST /patients`.

**Incorrect.** A create endpoint that ignores the header.
