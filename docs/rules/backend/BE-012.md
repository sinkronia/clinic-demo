**Rule.** Every business rule has at least one test. Integration tests run against real PostgreSQL through Testcontainers. `Microsoft.EntityFrameworkCore.InMemory` is banned (the build fails if it is referenced).

**Why.** InMemory does not enforce constraints, filters or SQL translation, so tests pass while production fails.

**Correct.** A `PostgreSqlContainer` fixture shared across the test collection.

**Incorrect.** `UseInMemoryDatabase(...)` or the SQLite provider as a stand-in.
