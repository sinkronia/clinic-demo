---
id: BE-004
title: API endpoints do not use DbContext; they call the Application layer
applies_to: ["backend/src/Clinic.Api/**"]
verified_by: ["Clinic.ArchitectureTests"]
status: active
since: v0.1
---
**Rule.** Code in the Api project never references the `DbContext` type. Endpoints map HTTP to a command or query handler from the Application layer and map the result back.

**Why.** Keeps business rules out of the HTTP layer and makes them testable without a web host.

**Correct.** `app.MapPost("/patients", (CreatePatientHandler h, ...) => ...)`.

**Incorrect.** Injecting `ClinicDbContext` into an endpoint lambda.
