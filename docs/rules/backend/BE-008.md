---
id: BE-008
title: No async void, .Result or .Wait()
applies_to: ["**/*.cs"]
verified_by: ["package:Microsoft.VisualStudio.Threading.Analyzers"]
status: active
since: v0.1
---
**Rule.** Never use `async void` (except event handlers), `.Result`, `.Wait()` or `.GetAwaiter().GetResult()` on tasks. Use `await`.

**Why.** Blocking on tasks causes deadlocks and thread-pool starvation; `async void` swallows exceptions.

**Correct.** `var patient = await handler.HandleAsync(command, ct);`

**Incorrect.** `var patient = handler.HandleAsync(command, ct).Result;`
