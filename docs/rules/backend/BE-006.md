**Rule.** `IgnoreQueryFilters()` is banned outside the Infrastructure project. Inside Infrastructure it is allowed only in an `Admin` namespace (this second part is review-only in v0.1).

**Why.** It bypasses the tenant filter (BE-005) and can leak data across tenants.

**Correct.** Let the global query filter work; use it in `Clinic.Infrastructure.Admin` for explicit cross-tenant tooling.

**Incorrect.** `db.Patients.IgnoreQueryFilters().CountAsync()` in an endpoint or handler.
