**Rule.** Every business entity in Domain implements `ITenantEntity` (`Guid TenantId`). The DbContext applies the tenant query filter to all of them.

**Why.** One missing tenant filter is a data leak between clinics.

**Correct.** `public sealed class Patient : ITenantEntity`.

**Incorrect.** A new entity without `TenantId`, or a hand-written `Where(x => x.TenantId == ...)` instead of the global filter.

**Exception.** Technical tables that are not business entities may be listed in the architecture test allowlist, with a justification in the PR.
