---
id: BE-003
title: Domain does not depend on EF Core, ASP.NET Core or Infrastructure
applies_to: ["backend/src/Clinic.Domain/**", "**/*.csproj"]
verified_by: ["Clinic.ArchitectureTests"]
status: active
since: v0.1
---
**Rule.** The Domain project has no reference (project, package or namespace) to Entity Framework Core, ASP.NET Core, or Infrastructure.

**Why.** Domain code must stay testable and independent of delivery and persistence details.

**Correct.** Entities are plain C# classes; mapping lives in Infrastructure.

**Incorrect.** `[Key]` / `[Table]` attributes, or `using Microsoft.EntityFrameworkCore;` in Domain.
