**Rule.** Inject `TimeProvider` and call `GetUtcNow()`. `DateTime.Now`, `DateTime.UtcNow`, `DateTimeOffset.Now` and `DateTimeOffset.UtcNow` are banned.

**Why.** Code that reads the system clock is untestable (appointments in the past, expiry, idempotency TTL).

**Correct.** `var now = _time.GetUtcNow();` and `FakeTimeProvider` in tests.

**Incorrect.** `var now = DateTime.UtcNow;`.
