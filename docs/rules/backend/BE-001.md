---
**Rule.** All C# code is formatted according to the `.editorconfig` synced from code-standards.

**Why.** Formatting debates and noisy diffs waste review time. Every tool and model must produce the same layout.

**Correct.** Run `dotnet format` before committing; `pwsh ./scripts/check.ps1` verifies it.

**Incorrect.** Hand-formatted code that `dotnet format --verify-no-changes` rewrites.
