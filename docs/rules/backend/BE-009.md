id: BE-009
title: Business errors are ProblemDetails with a stable code
applies_to: ["backend/src/**/*.cs"]
verified_by: ["Clinic.IntegrationTests"]
status: active
since: v0.1
---
**Rule.** Business errors are returned as RFC 9457 `ProblemDetails` with a stable machine-readable `code` extension (e.g. `patient.duplicate_document`). The text is never meant for end users; the UI translates by `code`.

**Why.** Codes are a stable contract; messages change and are language-specific.

**Correct.** `409` with `{ "status": 409, "code": "patient.duplicate_document" }`, asserted by an integration test.

**Incorrect.** Returning `Results.BadRequest("Patient already exists")`.
