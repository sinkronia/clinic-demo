**Rule.** Once a migration is merged to `main` it is never edited or deleted. Fix forward with a new migration.

**Why.** Edited migrations make environments diverge.

**Correct.** Add a new migration.

**Incorrect.** Changing an old migration file to "fix" a column.

**Exception.** None. (The automated check is a TODO in the demo, hence `proposed`.)
