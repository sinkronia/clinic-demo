# Glossary

Domain terms for code, docs and API contracts (rule GEN-004). Spanish is for UI and docs, English is for code.
To add a term, propose it first (skill `propose-rule`).

| Spanish (UI/docs) | English (code) | Definition |
| --- | --- | --- |
| Paciente | Patient | A person who receives care at a clinic. Archived, never deleted. |
| Cita | Appointment | A scheduled visit of a patient to the clinic, with a start and an end. |
| Sillón dental | DentalChair | The dental chair where a patient is treated; appointments are scheduled per chair. |
| Consultorio | Clinic | A dental clinic; the tenant of the system. |
| Odontograma | Odontogram | Chart of a patient's teeth and their condition. |
| Pieza | Tooth | One tooth of the odontogram. |
| Cara | ToothSurface | One surface of a tooth. |
| Evolución | ClinicalNote | A dated clinical note about the care given to a patient. |
| Adenda | Addendum | A later correction or addition to a clinical note; the original is never edited. |
| Plan de tratamiento | TreatmentPlan | The planned set of procedures for a patient. |
| Presupuesto | Quote | The priced proposal for a treatment plan. |
| Anamnesis | MedicalHistory | The patient's medical history collected at intake. |
